## Honest measurement caveat (unchanged from 08-04)

SERP discoverability is a proxy, not the official measure. Per Google's AI Optimization Guide (re-read today, last updated 2026-07-10), AI Overviews and AI Mode are grounded in the core Search index via retrieval-augmented generation and query fan-out. A page that does not surface in Google organic for a buyer query is not in the retrieval set that feeds the generative answer, so SERP presence is a defensible leading indicator of AI-answer eligibility. It is not the same as verbatim citation inside ChatGPT / Perplexity / Claude / Gemini, and it is not the GSC Generative AI performance report, which Google names as the honest primary measure. Treat these numbers as the SERP layer only. The probe ran through live web search, US locale, top ~8-10 organic per prompt.
